# Teitelbaum Prototype

Dieses Projekt ist ein **Prototyp** auf Basis von [PixiJS](https://pixijs.com/).  
Verschiedene Ideen und Funktionen für die Umsetzung des Projekts  
[**Quiz-App**](https://gitlab.fhnw.ch/eidi/2025hs/docs/-/blob/main/w02-eine-echte-app/projekt.adoc)  
aus dem Modul **Einstieg in die Informatik (EIDI)** zu testen.

## Mission

- Experimentieren mit verschiedenen Ideen...
- Testen von **UI- und Spielmechaniken**
- Schnelles Erproben neuer Funktionen (Timer, Frage-/Antwort-Logik, Animationen usw.)
- Frühzeitiges Sammeln von Feedback und Themen.
